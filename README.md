# TeleCare Terra — แพลตฟอร์มเทเลฟาร์มาซีและการแพทย์ทางไกล

เว็บไซต์ที่ใช้งานได้จริงจากชุดดีไซน์ "TeleCare Terra" (Terra — Organic Design) โดยคงหน้าตา UI เดิมทุกหน้า
และเพิ่มระบบหลังบ้าน (Node.js + Express) ให้ทุกปุ่มทำงานได้จริง

## เริ่มใช้งาน

```bash
npm install
npm start            # http://localhost:3000
```

ต้องใช้ Node.js 18.17 ขึ้นไป ข้อมูลเก็บในโฟลเดอร์ `data/` (สร้างอัตโนมัติพร้อมข้อมูลตัวอย่างในการรันครั้งแรก)

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm start` | เปิดเซิร์ฟเวอร์ |
| `npm run dev` | เปิดเซิร์ฟเวอร์แบบรีโหลดอัตโนมัติ |
| `npm test` | รันชุดทดสอบ API (12 ชุด) |
| `npm run build:css` | คอมไพล์ Tailwind CSS ใหม่ (หลังแก้คลาสใน HTML/JS) |
| `npm run reset-db` | ล้างข้อมูลทั้งหมดและสร้างข้อมูลตัวอย่างใหม่ |

### ทดลองการปรึกษาแบบสองฝั่ง
เปิดเบราว์เซอร์ 2 หน้าต่าง (หรือโหมดไม่ระบุตัวตน) — ฝั่งหนึ่งเข้าสู่ระบบเป็นผู้ป่วย อีกฝั่งเป็น `teerapat@telecare.terra`
แล้วเริ่มปรึกษาเภสัชกรร้าน "ฟาร์มาแคร์ พลัส (สาขาอารีย์)" ทั้งสองฝั่งจะแชทและวิดีโอคอลหากันได้จริง
(วิดีโอคอลข้ามเครือข่ายต้องเปิดผ่าน HTTPS และอาจต้องตั้งค่า TURN server)

## การตั้งค่า (environment variables)

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `PORT` | `3000` | พอร์ตเซิร์ฟเวอร์ |
| `DATA_DIR` | `./data` | ที่เก็บฐานข้อมูล JSON และไฟล์อัปโหลด |
| `DEMO_MODE` | `true` | `true` = เมื่อแพทย์/เภสัชกรไม่ได้ออนไลน์ ระบบตอบกลับอัตโนมัติ (ระบุว่าเป็นโหมดสาธิต) และแสดงบัญชีทดลอง/ลิงก์รีเซ็ตรหัสผ่านบนหน้าจอ — **ตั้งเป็น `false` เมื่อใช้งานจริง** |
| `PROMPTPAY_ID` | `0812345678` | เบอร์/เลขประจำตัวผู้เสียภาษีพร้อมเพย์ของร้านสำหรับสร้าง QR |

| `PUBLIC_URL` | – | URL หลักของเว็บ (ใช้กับ OAuth callback) |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | – | เปิดใช้ "เข้าสู่ระบบด้วย Google" (callback: `/auth/google/callback`) |

| `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` | – | TURN server สำหรับวิดีโอคอลผ่าน NAT/เครือข่ายองค์กร |

## สิ่งที่ต้องเชื่อมต่อเพิ่มก่อนเปิดให้บริการจริง

ระบบทำงานครบทุกขั้นตอน แต่บางส่วนต้องใช้บริการภายนอกที่ต้องมีสัญญา/บัญชีของบริษัท:

- **การชำระเงิน** — QR พร้อมเพย์สร้างตามมาตรฐาน EMVCo สแกนจ่ายได้จริง แต่ระบบยังยืนยันการโอนจากการกดยืนยันของผู้ใช้ และบัตรเครดิตตรวจสอบรูปแบบ (Luhn/วันหมดอายุ) เท่านั้น ต้องเชื่อม payment gateway (เช่น Omise, 2C2P, GB Prime Pay) ใน `server/payments.js`
- **อีเมล/SMS** — ลิงก์ตั้งรหัสผ่านใหม่ยังไม่ถูกส่งออก (โหมดสาธิตแสดงลิงก์บนจอ และพิมพ์ใน log)
- **การจัดส่ง** — สถานะและตำแหน่งไรเดอร์คำนวณจากเวลาจัดส่งของร้าน ต้องเชื่อม API ผู้ให้บริการขนส่งเพื่อ GPS จริง
- **หมอพร้อม / ThaiID** — ต้องได้รับอนุมัติการเชื่อมต่อจากหน่วยงานรัฐ
- **ภาษาอังกฤษ** — ปัจจุบันรองรับภาษาไทย
- **ฐานข้อมูล** — ไฟล์ JSON เหมาะกับการใช้งานขนาดเล็กเครื่องเดียว หากมีผู้ใช้จำนวนมากควรย้ายไป PostgreSQL

รูปภาพบุคคลและร้านยาใช้ไฟล์จากชุดดีไซน์เดิม (โฮสต์บน Google) หากโหลดไม่ได้ ระบบจะแสดงภาพแทนอัตโนมัติ

## โครงสร้างโปรเจกต์

```
server.js              จุดเริ่มเซิร์ฟเวอร์ เส้นทางหน้าเว็บ และตัวแจ้งเตือนสถานะการจัดส่ง
server/api.js          REST API ทั้งหมด
server/consult.js      การปรึกษา ข้อความ ใบสั่งยา (ตรวจประวัติแพ้ยา)
server/bot.js          ผู้ตอบอัตโนมัติในโหมดสาธิต
server/logic.js        ระยะทาง เวลาเปิด-ปิด ตารางแพทย์ สถานะคำสั่งซื้อ
server/payments.js     QR พร้อมเพย์ และตรวจสอบบัตร
server/print.js        ใบสั่งยา ใบเสร็จ ใบรับรองแพทย์ (พิมพ์/บันทึก PDF)
server/oauth.js        Google / LINE Login
server/seed.js         ข้อมูลตัวอย่าง (แพทย์ 9 ท่าน ร้านยา 9 แห่ง ผู้ป่วยตัวอย่าง)
public/*.html          หน้าเว็บจากดีไซน์เดิม
public/js/app.js       ส่วนกลาง: API, เฮดเดอร์, หน้าต่าง, ชำระเงิน, เรียลไทม์
public/js/pages/*.js   สคริปต์ของแต่ละหน้า
tailwind.config.js     ธีมสี/ฟอนต์จากดีไซน์ (คอมไพล์เป็น public/css/tailwind.css)
test/api.test.js       ชุดทดสอบ
```
